Selected work

Three apps, live right now.

Small in scope, finished in behaviour. Each one does a single job, works offline, and keeps your data on your own device.

  1. 01

    3000 Words — English vocabulary trainer

    A browser-based trainer for the 3000 most useful English words and phrases, with Polish translations and example sentences. Your progress is stored locally in IndexedDB, so there is no account to create and nothing sent to a server.

    • Vanilla JS
    • IndexedDB
    • GitHub Pages
    Live↗ Source↗
  2. 02

    PSM I — Practice Tests

    Interactive practice tests for the Professional Scrum Master I certification. One HTML page, zero dependencies — open it, pick a set, and check yourself as many times as you like.

    • Single page
    • Zero dependencies
    • Exam prep
    Live↗ Source↗
  3. 03

    AZ-900 — Practice Tests

    Interactive practice tests for Microsoft Azure Fundamentals (AZ-900), built the same way as the PSM I set: a single page, no build step, no backend.

    • Single page
    • Zero dependencies
    • Exam prep
    Live↗ Source↗
